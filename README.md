# FungiGut – downstream analysis

R code and processed data behind the figures and supplementary tables of the FungiGut paper. FungiGut profiles gut fungi in shotgun metagenomes against a curated database (FungiGutDB). Its results are compared with MiCoP on:

- **Simulated mock communities**: Set1 (bacteria + fungi), Set1 after removing bacterial reads (`Set1_filtered`) and Set2 (fungi only).
- **Reference mocks**: ZymoBIOMICS and a Pool DNA mock.
- **Two real cohorts**: non-responsive coeliac disease patients (NRCD) and MetaCardis controls.

The FungiGut pipeline itself (QC, host and prokaryote removal, BWA alignment) produces the phyloseq objects in `data/`. This repository starts from those objects.

## Layout

```
R/          analysis scripts (run from the repository root)
data/       phyloseq objects (.rds), expected mock compositions, read statistics, FungiGutDB metadata
results/    figures and tables generated by the scripts
```

| Folder | Content |
|---|---|
| `data/mock_sets/` | Set1, Set1_filtered and Set2 FungiGut profiles and expected compositions (`set1_microbiome.tsv`, `set2_mycobiome.tsv`) |
| `data/zymo/`, `data/pool_dna/` | FungiGut and MiCoP profiles of the reference mocks; expected Pool DNA composition |
| `data/nrcd/`, `data/metacardis/` | FungiGut and MiCoP profiles of both cohorts: `*_raw.rds` are read counts, the rest are relative abundances |
| `data/processed/` | Batch-corrected cohort objects (output of `03_batch_correction.R`) |
| `data/seqkit/` | `seqkit stats` of raw, QC, host-removed and bacteria-removed reads |
| `data/fungigut_db/` | FungiGutDB species list, genome report, source studies and iTOL phylum legend |

## Running

Requires R ≥ 4.4 with phyloseq, MMUPHin, microbiome, vegan, ggplot2, ggpubr, rstatix, dplyr, tidyr, tibble, readr, readxl and stringr.

```r
install.packages(c("vegan", "ggplot2", "ggpubr", "rstatix", "dplyr", "tidyr", "tibble", "readr", "readxl", "stringr", "BiocManager"))
BiocManager::install(c("phyloseq", "MMUPHin", "microbiome"))
```

```sh
Rscript R/run_all.R          # whole analysis
Rscript R/04_diversity.R     # or a single step
```

`04` and `05` read `data/processed/`, which `03` generates. The batch-corrected objects are committed, so `04` and `05` also run on their own.

## Notes

- **Batch correction.** MMUPHin is run with `batch = "Group"`. The cohort (NRCD vs MetaCardis) is fully confounded with disease status, so the correction also shrinks the NRCD/Control difference that is later tested with PERMANOVA.
- **Chao1 for MiCoP.** MiCoP count tables contain no singletons, so Chao1 for MiCoP is a lower bound and phyloseq warns about it.
- **Figure 4 tests.** Set1 and Set1_filtered are the same samples before and after removing bacterial reads, but they are compared with an unpaired Wilcoxon test.
